# منصة أثر — نسخة عرض ثابتة

نسخة HTML ثابتة من موقع منصة أثر لتطوير حوكمة القطاع غير الربحي، جاهزة للنشر عبر GitHub Pages.

## الصفحات

- `index.html` — الرئيسية
- `founder.html` — المؤسس
- `assess.html` — قيم جمعيتك
- `forms.html` — مكتبة النماذج
- `articles.html` — المحتوى والمعرفة
- `directory.html` — دليل الجمعيات

## النشر عبر GitHub Pages

1. من إعدادات الريبو (Settings → Pages)
2. اختر Source: **Deploy from a branch**
3. اختر Branch: **main**, المجلد: **/ (root)**
4. احفظ، وهيظهر رابط الموقع بعد دقيقة أو اتنين على شكل:
   `https://ali-hassan-ali.github.io/a3r.sa/`
